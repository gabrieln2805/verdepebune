# Map style and glyphs (verde-pe-bune)

- `style.json` (light) and `style-dark.json`: MapLibre styles generated by
  `exports/verde_pe_bune/map_assets.py` for the Protomaps basemap v4 tile schema. Colours follow the
  Protomaps "light" and "dark" flavours (map design: CC0). The `@protomaps/basemaps` style code (BSD-3) is not
  vendored and not copied. No sprite: the tiles contain no points of interest and the styles use no icons.
- Every URL is same-origin and relative to the page: tiles `pmtiles://data/basemap-bucuresti-<date>.pmtiles`
  (needs the `pmtiles` JS protocol), glyphs `map/glyphs/{fontstack}/{range}.pbf`.
- Tiles: © OpenStreetMap contributors, ODbL 1.0, built by Protomaps (daily build) and filtered by
  `geo/verde_pe_bune/basemap.py` (no `pois`, no `landcover`, no house numbers). Not covered by the repository
  MIT licence.
- `glyphs/`: Noto Sans Regular and Medium, ranges 0-255, 256-511, 512-767 (ș ț) and 8192-8447, from
  protomaps/basemaps-assets. SIL Open Font License 1.1, see `glyphs/OFL.txt`. Not offered as a stand-alone
  font download.
