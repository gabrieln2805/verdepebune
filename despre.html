Despre proiect și contact

Ce este Verde pe bune

Verde pe bune este un site care arată, cu date publice, cât verde se vede în București. Nu dăm o singură cifră, pentru că „verde” poate însemna lucruri diferite. Arătăm măsuri separate, fiecare cu definiția, anul și limitele ei. Pe pagina Cum am calculat găsești regulile și sursele.

Ce nu este

  • Nu este o sursă oficială și nu înlocuiește datele autorităților.
  • Nu este un clasament și nu spune dacă cineva respectă sau nu o normă.
  • Nu oferă sfaturi juridice, fiscale, medicale sau financiare.
  • Nu susține nicio persoană, instituție sau partid.

De unde vin datele

Toate datele vin din surse publice sau deschise: Copernicus (imagini din satelit), Eurostat (populație), INS (populația pe sectoare, doar ca referință), ANCPI (limitele sectoarelor) și OpenStreetMap (hărți făcute de voluntari). Valorile sunt calculate cu reguli fixe, nu de un model de inteligență artificială. Fișierele pe care le publicăm pot fi descărcate, cu licențele lor, din secțiunea Date deschise.

Datele tale

Noi nu colectăm date personale. Nu folosim cookie-uri, analiză de trafic sau servicii externe: hărțile, fonturile și datele se încarcă de pe același server ca site-ul.

Cel mai apropiat spațiu verde

Dacă alegi „Folosește locația mea”, browserul îți cere permisiunea. Poziția ta, strada căutată și punctul ales pe hartă sunt folosite doar în browserul tău, pentru calculul distanțelor. Nu le trimitem nicăieri și nu le salvăm. Browserul sau telefonul pot folosi propriile servicii de localizare (de exemplu Google sau Apple), după setările tale. Harta se încarcă pe bucăți: pentru zona pe care o vezi, browserul cere de pe server bucățile de hartă pentru acea zonă (aproximativ un cartier).

Găzduire

Site-ul este găzduit de GitHub (SUA), prin GitHub Pages. GitHub înregistrează tehnic, pentru securitate, adresa IP a vizitatorilor. Noi nu avem acces la aceste jurnale și nu le folosim. Transferul către SUA se face în baza cadrului UE-SUA privind protecția datelor (Data Privacy Framework). Mai multe, în declarația de confidențialitate GitHub (în engleză).
